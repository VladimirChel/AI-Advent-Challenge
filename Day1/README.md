\# AI Chat (Python)



Простой чат с нейросетью на Python с GUI.



\## Возможности



\* Интерфейс на \*\*customtkinter\*\*

\* Чат с нейросетью

\* Настройки:



&#x20; \* API ключ

&#x20; \* Base URL

&#x20; \* выбор модели (OpenAI / DeepSeek)



\## Установка



```bash

pip install -r requirements.txt

```



\## Запуск



```bash

python app.py

```



\## Зависимости



\* customtkinter

\* requests



\## Настройки



Укажите в программе:



\* `api\_key`

\* `base\_url`

\* модель



По умолчанию base URL:



```

https://api.proxyapi.ru/openai/v1

```
