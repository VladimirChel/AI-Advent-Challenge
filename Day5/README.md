# 🧪 LLM Experiment Lab

Приложение для тестирования и сравнения ответов разных LLM-сценариев с автоматической оценкой через judge-модель.

---

## 🚀 Возможности

* Запуск серии запросов к LLM с разными параметрами
* Поддержка нескольких сценариев (temperature, max_tokens и др.)
* Автоматическая оценка ответов (LLM-as-a-judge)
* Генерация **HTML-отчёта** с:

  * ответами моделей
  * техническими параметрами
  * сравнительными таблицами
  * графиками (latency, токены, score)
* Гибкая настройка:

  * system prompt
  * критерии оценки
  * параметры judge-модели

---

## 🧱 Архитектура

Основные компоненты:

* **LLMGatewayClient** — отправка запросов к API
* **ExperimentRunner** — запуск сценариев и оценка
* **App (UI)** — интерфейс на `customtkinter`
* **HTML report builder** — генерация отчёта

  * global system prompt

  * список конфигураций запросов
* **Judge / критерии**

  * критерии оценки
  * prompt judge-модели

---

## 📊 Как работает

1. Ты задаёшь вопрос
2. Приложение запускает несколько сценариев
3. Каждый сценарий = отдельный запрос к LLM
4. Затем запускается judge-модель
5. Генерируется HTML-отчёт

---

## 📄 Результат

После запуска создаётся:

```
/reports/llm_experiment_YYYYMMDD_HHMMSS.html
```

И автоматически открывается в браузере.

```json
  {
    "name": "Строгий эксперт",

    "max_tokens": 800
  }

```

---

## 🧠 Judge-модель

Judge получает:

* вопрос
* критерии
* ответы всех сценариев
* технические параметры

И возвращает:

* оценки (1–10)
* сильные/слабые стороны
* анализ влияния параметров
* победителя

---

## ⚠️ Ограничения

* Требуется доступный LLM gateway (`/generate`)
* Judge может ошибаться (это всё ещё LLM)
