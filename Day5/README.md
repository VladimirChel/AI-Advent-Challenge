LLM Experiment Lab

Интерактивное desktop-приложение для проведения экспериментов с LLM (Large Language Models), сравнения разных сценариев генерации и автоматической оценки ответов через подход LLM-as-a-judge.

🚀 Возможности
🔁 Запуск серии запросов к LLM с разными параметрами
⚙️ Гибкая настройка сценариев (JSON)
🧠 Поддержка нескольких моделей (OpenAI, Anthropic, Google и др.)
📊 Автоматическая оценка ответов (judge-модель)
📈 Визуализация:
время ответа
количество токенов
итоговые оценки
📄 Генерация HTML-отчёта с подробным анализом
💾 Сохранение сценариев и запросов
🏗 Архитектура

Приложение состоит из нескольких ключевых компонентов:

LLMGatewayClient — клиент для отправки запросов к API (/generate, /health, /models)
ExperimentRunner — выполнение серии сценариев и их оценка
ScenarioConfig — конфигурация одного сценария
GatewayResponse — результат запроса + технические метрики
GUI (CustomTkinter) — интерфейс пользователя
📦 Установка
git clone <repo>
cd <repo>
pip install -r requirements.txt

Создай .env файл:

REQUEST_URL=http://127.0.0.1:8000/generate
DEFAULT_MODEL=openai/gpt-4o-mini
▶️ Запуск
python llm_experiment_lab2.py
🧪 Как это работает
Вводишь вопрос
Определяешь сценарии (JSON):
модель
temperature
max_tokens
system_prompt
Приложение:
отправляет запросы ко всем сценариям
собирает ответы и метрики
Judge-модель:
оценивает ответы по критериям
анализирует влияние параметров
Генерируется HTML-отчёт
🧾 Пример сценариев
[
  {
    "name": "Базовый ответ",
    "enabled": true,
    "model": "openai/gpt-4o-mini",
    "system_prompt": "Ты полезный ассистент.",
    "temperature": 0.7,
    "max_tokens": 1200
  }
]
📊 HTML-отчёт содержит
ответы всех сценариев
технические параметры (latency, токены и др.)
таблицу оценок
сравнительный анализ
вывод победителя
графики (Chart.js)
🧠 Judge-модель

Используется подход:

LLM оценивает ответы других LLM

Оценка включает:

точность
креативность
следование задаче
риск галлюцинаций
анализ влияния параметров (temperature, tokens и др.)
⚙️ Настройки
Основные
Request URL — endpoint gateway
Model — модель по умолчанию
Judge
temperature
max_tokens
system prompt
критерии оценки
